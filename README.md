## Сделанное
- `isInteger(n)` - проверяет, является ли число целым используя побитовые операторы

- `even()` - возвращает массив четных чисел от 2 до 20 включительно

- `sumTo(n)` - считает сумму чисел до заданного используя цикл

- `recSumTo(n)` - считает сумму чисел до заданного используя рекурсию

- `factorial(n)` - считает факториал заданного числа

- `isBinary(n)` - определяет, является ли число двойкой, возведенной в степень

- `fibonacci(n)` - находит N-е число Фибоначчи

- `getOperationFn(initialValue, operatorFn)` - принимает начальное значение и функцию операции и возвращает функцию - выполняющую эту операцию 

- `sequence(start = 0, step = 1)` - функция создания генератора арифметической последовательности

- `deepEqual(firstObject, secondObject)` - принимает два значения и возвращает true только в том случае, если они имеют одинаковое значение или являются объектами с одинаковыми свойствами, значения которых также равны при сравнении с рекурсивным вызовом deepEqual.
